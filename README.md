Alfa News Agent

ИИ-агент для анализа новостей, разрабатываемый в рамках Alpha Hackathon — трек «Новостная аналитика».

Проект использует OpenAI-совместимый API для взаимодействия с большими языковыми моделями (LLM) и служит основой для создания агента, способного анализировать новости и формировать аналитические выводы.

Технологии

Python — основной язык разработки

OpenAI Python SDK — взаимодействие с API моделей

OpenAI-совместимый API — доступ к языковым моделям

Git и GitHub — контроль версий и совместная работа

Установка и запуск

1. Клонирование репозитория

git clone git@github.com:AzatBadretdinov/alfa-news-agent.git
cd alfa-news-agent

Также можно клонировать репозиторий через HTTPS.

2. Создание виртуального окружения

python -m venv .venv

Активация в Windows PowerShell:

.\.venv\Scripts\Activate.ps1

3. Установка зависимостей

python -m pip install openai

4. Настройка доступа к API

Для работы необходим действующий API-ключ и адрес API, предоставленный организаторами хакатона.

Перед запуском необходимо настроить параметры подключения и выбрать доступную модель.

Важно: не публикуйте API-ключи и другие секретные данные в GitHub. У каждого участника команды должен быть корректно настроен доступ к API.

5. Проверка подключения

Запустите команду:

python test_llm.py

При корректной конфигурации и доступности API скрипт отправит запрос выбранной модели и выведет её ответ.

Совместная работа

Репозиторий предназначен для совместной разработки в рамках хакатона.

Рекомендуемый порядок работы:

Получить актуальную версию проекта из репозитория.

Создать отдельную ветку для своей задачи.

Внести изменения и проверить их локально.

Отправить изменения в GitHub.

При необходимости создать Pull Request для проверки изменений командой.

Безопасность

Не храните API-ключи непосредственно в публикуемом исходном коде.

Не добавляйте в репозиторий .env, виртуальное окружение и другие файлы с секретными данными.

Если ключ стал доступен посторонним, запросите его замену у организаторов.
